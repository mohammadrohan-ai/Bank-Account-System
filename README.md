🏦 Bank Account Management System

A beginner-friendly Bank Account Management System built with Python using Object-Oriented Programming (OOP). This project allows users to create multiple bank accounts, deposit and withdraw money, and view account information through a simple command-line interface.

✨ Features
🏦 Create multiple bank accounts
🔢 Automatically generate random account numbers
💰 Deposit money into accounts
💸 Withdraw money with balance validation
🔍 Search accounts by account holder name
📋 Display individual account information
📊 Display all accounts
✅ Input validation and error handling
💻 Simple command-line interface
🛠️ Technologies

Python • OOP • Random Module

📚 Concepts Practiced
Classes and objects
Constructors (__init__)
Instance attributes and methods
Lists of objects
Loops and conditional statements
Input validation
Exception handling
🚀 How to Run
Clone this repository.
Open the project folder.
Run main.py using Python.
🎯 Purpose

Built as a practical project to strengthen my understanding of Python OOP, object management, and basic application development.

Note: This is an educational project, not a real banking application. Account data is stored in memory and is lost when the program exits.
